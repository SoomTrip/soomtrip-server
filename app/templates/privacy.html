숨트립(SoomTrip) 개인정보처리방침

시행일자: 2026년 9월 10일
개인정보처리자: 숨트립 팀
개인정보 문의: 서비스 내 문의 채널 또는 숨트립 팀 공식 연락처

숨트립(SoomTrip)(이하 “서비스”)은 이용자의 개인정보를 중요하게 생각하며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 본 개인정보처리방침은 서비스가 어떤 개인정보를 수집하고, 어떤 목적으로 이용하며, 어떻게 보호하는지 안내하기 위해 마련되었습니다.

서비스는 이용자의 주민등록번호, 신용카드 정보 등 민감정보를 수집하지 않습니다. 또한 실시간 위치정보를 수집하지 않으며, 이용자가 선택하거나 저장한 관광지의 좌표 정보만 추천 및 경로 계산을 위해 처리할 수 있습니다.

서비스는 다음의 개인정보를 수집·이용할 수 있습니다.

2. 개인정보 수집 방법

  • 카카오 로그인을 통해 회원 정보를 수신합니다.
  • 이용자가 앱에서 직접 입력하거나 선택한 정보를 수집합니다.
  • 이용자가 업로드한 그림일기 이미지를 수집합니다.
  • 서비스 이용 과정에서 접속 로그 및 오류 로그가 자동으로 생성될 수 있습니다.

3. 개인정보의 이용 목적

  • 회원 식별 및 로그인 유지
  • 여행 취향 테스트 결과 저장 및 취향 기반 여행지 추천
  • 저장한 여행지 및 관광지 관리
  • 친구 추가, 친구 목록 조회, 저장 여행지 공유
  • 그림일기 작성, 조회, 수정, 삭제
  • 그림일기 작성 시 도장 지급 및 도장판 표시
  • 선택 관광지 기반 경로 추천 및 저장
  • 서비스 오류 분석, 보안 관리, 부정 이용 방지

4. 개인정보의 제3자 제공

서비스는 이용자의 개인정보를 원칙적으로 외부에 제공하지 않습니다. 다만 다음의 경우에는 필요한 범위 내에서 정보가 제공될 수 있습니다.

  • 이용자가 친구에게 저장한 여행지를 공유하는 경우, 해당 친구에게 공유 대상 여행지 및 관광지 정보가 제공될 수 있습니다.
  • 이용자가 그림일기를 공개로 설정한 경우, 공개 대상에게 해당 그림일기 정보가 표시될 수 있습니다.
  • 법령에 따라 수사기관 또는 관계기관의 적법한 요청이 있는 경우 개인정보가 제공될 수 있습니다.

5. 외부 서비스 이용 및 처리위탁

서비스 제공을 위해 다음 외부 서비스를 이용합니다.

업체 또는 서비스 이용 목적 처리되는 정보
Kakao 소셜 로그인 카카오 회원 식별자, 닉네임, 프로필 이미지
Supabase 데이터베이스 및 이미지 Storage 운영 회원 정보, 취향 결과, 저장 여행지, 친구 정보, 그림일기, 이미지 경로, 경로 정보 등
한국관광공사 Tour API 여행지 및 관광지 정보 조회 여행지 및 관광지 검색 조건
Naver Directions API 자동차 경로 계산 선택한 관광지 좌표
TMAP API 도보 경로 계산 선택한 관광지 좌표
OpenAI API 추천 문구 생성 기능이 사용되는 경우 여행지명, 취향 점수, 추천 점수 등 추천 문구 생성에 필요한 정보

경로 계산 및 추천 문구 생성 과정에서는 카카오 ID, 사용자 코드, Refresh Token, 그림일기 이미지 등 직접 식별 가능한 정보는 전송하지 않습니다.

6. 개인정보의 국외 이전

서비스는 Supabase 및 OpenAI API 등 국외 사업자의 클라우드/API 서비스를 사용할 수 있습니다.

이전받는 자 이전 국가 이전 항목 이전 목적 보유 기간
Supabase, Inc. 서비스 인프라 운영 국가 서비스 DB 및 Storage에 저장되는 개인정보 데이터 저장 및 이미지 보관 회원탈퇴 또는 삭제 시까지
OpenAI, L.L.C. 서비스 인프라 운영 국가 추천 문구 생성에 필요한 여행지명, 취향 및 추천 관련 정보 AI 추천 문구 생성 해당 외부 서비스의 정책에 따름

7. 개인정보의 보유 및 파기

서비스는 개인정보의 수집 및 이용 목적이 달성되면 지체 없이 해당 정보를 파기합니다. 회원탈퇴 시 회원 정보, 취향 결과, 친구 관계, 저장 여행지, 그림일기, 도장, 경로 정보 및 Supabase Storage에 저장된 그림일기 이미지를 삭제합니다.

  • 회원탈퇴 시 회원 정보 및 관련 데이터 삭제
  • 저장 여행지 삭제 시 해당 여행지 및 관련 관광지 정보 삭제
  • 그림일기 삭제 시 해당 그림일기 정보 삭제
  • 회원탈퇴 시 Supabase Storage에 저장된 그림일기 이미지 삭제

전자적 파일 형태의 개인정보는 복구할 수 없는 방법으로 삭제하며, 종이 문서 형태의 개인정보를 보관하는 경우 분쇄 또는 소각합니다.

8. 이용자의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보에 대해 열람, 정정, 삭제, 처리정지를 요청할 수 있습니다.

  • 프로필 정보는 앱 내 마이페이지에서 수정할 수 있습니다.
  • 취향 결과, 저장 여행지, 그림일기, 친구 관계 등은 앱 내 기능을 통해 삭제할 수 있습니다.
  • 회원탈퇴를 요청하면 계정 및 관련 개인정보가 삭제됩니다.
  • 추가 문의는 서비스 내 문의 채널 또는 숨트립 팀 공식 연락처를 통해 요청할 수 있습니다.

9. 앱 접근 권한 안내

서비스는 기능 제공을 위해 다음 권한을 요청할 수 있습니다.

권한 사용 목적
사진, 파일 또는 저장공간 그림일기 이미지 업로드
카메라 사진을 촬영해 그림일기에 첨부하는 기능이 있는 경우

선택 권한을 허용하지 않아도 기본 서비스 이용은 가능하나, 해당 권한이 필요한 일부 기능은 제한될 수 있습니다.

10. 만 14세 미만 아동의 개인정보

서비스는 원칙적으로 만 14세 미만 아동의 개인정보를 고의로 수집하지 않습니다. 만 14세 미만 아동의 개인정보 처리가 필요한 경우 법정대리인의 동의를 받는 등 관련 법령에 따른 조치를 이행합니다.

11. 자동화된 의사결정에 관한 사항

서비스는 이용자의 취향 결과를 바탕으로 여행지를 추천할 수 있습니다. 해당 추천은 여행 탐색을 돕기 위한 참고 정보이며, 이용자에게 법적 효과를 발생시키거나 중대한 영향을 미치는 자동화된 의사결정은 수행하지 않습니다.

12. 개인정보의 안전성 확보 조치

서비스는 개인정보 보호를 위해 다음 조치를 시행합니다.

  • 비밀번호 대신 카카오 로그인을 통한 인증 사용
  • Refresh Token 원문이 아닌 Hash 값 저장
  • 인증 토큰 기반 API 접근 제어
  • Supabase Storage Private Bucket 사용
  • 그림일기 이미지 조회 시 Signed URL 사용
  • 개인정보 접근 권한 최소화
  • 서비스 운영에 필요한 API Key 및 Secret의 서버 측 관리

본 개인정보처리방침은 시행일자부터 적용됩니다. 내용이 변경되는 경우 서비스 내 공지 또는 개인정보처리방침 페이지를 통해 안내합니다.
